# 出会い方診断サイト 収益導線設計メモ

## 目的

* 診断結果やコラムから、ユーザーの状態に合った外部導線へ自然につなげる。
* 不安を煽らず、選択肢の整理・気持ちの整理・次の行動の補助として導線を置く。
* 外部URL実装前に、どのページにどの導線を置くかを整理する。

## 前提

* 現時点では外部URL・販売URL・アフィリエイトURLは未実装。
* 今後追加する可能性がある導線：

  * 占い鑑定販売
  * note
  * ブログ
  * マッチングアプリアフィリエイト
  * 電話占いアフィリエイト
  * 結婚相談所アフィリエイト
* 断定表現は避ける。
* 「必ず出会える」「結婚できる」「成功する」などの表現は使わない。
* PR表記や広告表記が必要な箇所は、実装時に明記する。

## ページ別導線案

### トップページ /

* 目的：サイト全体の入口。
* 優先導線：

  1. 診断ページ /diagnosis
  2. コラム一覧 /articles
  3. 気持ち整理 /fortune
* 外部導線は強く出しすぎない。
* 将来的には下部に「次にできること」枠として、note・ブログ・占い鑑定への控えめな案内を置く。

### 診断ページ /diagnosis

* 目的：診断完了後に、結果タイプに合わせて次の選択肢へつなげる。
* 優先導線：

  1. 結果タイプ別おすすめコラム
  2. /matching-apps
  3. /fortune
  4. /articles
* 外部導線案：

  * matching_app / marriage_app：マッチングアプリ比較・アフィリエイト導線
  * agency：結婚相談所比較・資料請求系アフィリエイト導線
  * self_reflection / rest：占い鑑定、note、ブログ、電話占い導線
  * introduction / community / event：コラム・ブログ導線中心
* 実装時は、いきなり外部ボタンを大きく出すより、内部コラムを挟んでから外部導線へつなげる。

### /matching-apps

* 目的：マッチングアプリを選択肢のひとつとして整理するページ。
* 外部導線候補：

  * マッチングアプリアフィリエイト
  * アプリ比較記事
  * 登録前チェックリスト
* 表現方針：

  * 「おすすめランキング」よりも「選ぶ前に確認したいこと」寄り。
  * 安全面、目的、年齢層、真剣度、料金、使いやすさを比較軸にする。
* 実装時の注意：

  * PR表記を入れる。
  * 特定サービスを断定的に推奨しない。
  * 外部リンクには target="_blank" と rel="noopener noreferrer" を付ける。

### /fortune

* 目的：迷った気持ちを整理する補助ページ。
* 外部導線候補：

  * 占い鑑定販売
  * 電話占いアフィリエイト
  * note
  * ブログ
* 表現方針：

  * 「占いで答えを決める」ではなく、「気持ちを整理する補助」として案内する。
  * 不安を煽らない。
* 導線順の案：

  1. 自分で整理するコラム
  2. note / ブログ
  3. 占い鑑定
  4. 電話占い

### /articles

* 目的：コラム一覧から、内部回遊を作る。
* 外部導線候補：

  * 記事下部に控えめな関連導線を置く。
  * 全記事に同じ外部リンクを入れるのではなく、記事テーマに合わせて出し分ける。
* 実装方針：

  * コラム一覧自体は内部導線中心。
  * 外部導線は各記事本文末尾のCTAで自然に出す。

## 記事別導線案

* 候補導線：

  * /matching-apps
  * マッチングアプリアフィリエイト
  * アプリ比較記事
* 外部導線優先度：高

### 自然な出会いが少ないと感じたときに考えたいこと

* 候補導線：

  * /diagnosis
  * /articles
  * ブログ
  * note
* 外部導線優先度：中

### 紹介で出会うときに無理をしない考え方

* 候補導線：

  * /diagnosis
  * /articles
  * ブログ
  * note
* 外部導線優先度：低〜中

### 出会い方に迷ったとき、自分に合う選び方

* 候補導線：

  * /diagnosis
  * /matching-apps
  * /fortune
  * note
  * ブログ
* 外部導線優先度：中

### 出会いに疲れたとき、少しペースを整える考え方

* 候補導線：

  * /fortune
  * 占い鑑定販売
  * note
  * 電話占いアフィリエイト
* 外部導線優先度：高

## 実装優先順位

### 第1段階：内部導線の維持

* 現在完了済み。
* 診断、コラム、fortune、matching-apps の内部回遊を維持する。

### 第2段階：占い・note・ブログ導線

* /fortune に最初に追加する。
* 記事「出会いに疲れたとき」から /fortune へつなげたうえで、占い鑑定やnoteへ案内する。
* いきなり強い販売ボタンにしない。

### 第3段階：マッチングアプリ導線

* /matching-apps と、アプリ関連コラムに追加する。
* 比較軸を整理したうえで外部リンクを置く。
* PR表記を明記する。

### 第4段階：結婚相談所導線

* agency タイプの診断結果向けに検討する。
* ただし、出会い方診断サイトの主軸から強く外れないようにする。
* 必要なら専用ページ追加を検討する。

### 第5段階：電話占い導線

* /fortune と「出会いに疲れたとき」記事に限定して検討する。
* 不安訴求を避ける。

## 実装時の共通注意

* 外部リンクはすべて新規タブで開く。
* rel="noopener noreferrer" を付ける。
* PR表記・広告表記を入れる。
* 断定表現を避ける。
* 診断結果を根拠に「あなたはこれを使うべき」と言わない。
* 「選択肢のひとつ」「必要に応じて」「気持ちを整理する補助」という表現にする。
* 追加後は、内部リンク・外部リンク・sitemap・metadata に影響がないか確認する。
